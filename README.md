# 연료전지 + 하이브리드 콘덴싱에어컨 사업성 시뮬레이터

공동주택 1,000세대에 연료전지(PureCell 400 NG)와 하이브리드 콘덴싱에어컨을 적용할 때의 사업성을 계산하는 Streamlit 앱입니다.
Windows 11 / Python 3.12 / Streamlit. 모든 입력값은 화면에서 수정할 수 있고, 결과는 Excel로 내려받을 수 있습니다.

**계산 흐름:** 입력조건 → 월별 에너지 수지 → 연료비 → 매전·매열 수익 → HPS 보상 역산 → 고객 편익 → 연도별 현금흐름 → NPV·IRR → 투자비 회수 가능성

## 실행 (Windows)
`run.bat` 더블클릭 (가상환경 생성 → 패키지 설치 → 앱 실행), 또는 PowerShell에서:
```powershell
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
- 코드를 수정한 뒤에는 실행 중인 앱을 `Ctrl+C`로 종료하고 다시 실행하세요. (이전 모듈이 메모리에 남아 오류가 날 수 있음)
- 테스트: `python -m pytest -q tests`
- 화면 헤드리스 점검(기본·입력완료·S2·엄격보류·수동 대수·성능저하 시나리오): `python tests/run_apptest.py`, `python tests/run_apptest2.py`

## 핵심 계산 기준
- **열수요 환산:** 난방 = 130세대 실측 × (1,000/130) × (112.4/59) (면적비), 급탕 = 130세대 실측 × (1,000/130) × (4/4) (거주인원비, 면적비 아님). 1 MWh = 860 Mcal = 3.6 GJ.
- **냉방부하:** 59.2 W/㎡ × 84.8㎡ × (남서 60%×1.08 + 남동 40%×1.02) → 세대당 약 5.30 kW, 1,000세대 약 5.30 MW. 6~9월 등가전부하시간(54/172/200/84h) 적용. COP 일반 3.5 / 하이브리드 전기 5.2 / 열 1.7. 증발수 6 L/kWh_cool.
- **열 사용 우선순위:** 동절기 급탕→난방, 하절기 냉방→급탕→잔여난방, 봄·가을 급탕→잔여난방. 계절 구분은 화면에서 수정 가능.
- **가스비:** 3,798.2 MJ/h × 단가(25.0573원/MJ, 부가세 10% 가산이 기본) × 8,760h × 이용률 95% × 대수.
- **매열 수익:** 동절기 난방·급탕 공급열만 인정. 단가 = 한국지역난방공사 동절기 열요금 **115.59원/Mcal (99.41원/kWh)의 70%**. 하절기 냉방용 열(무상)·봄·가을 잉여열은 0원.
- **기준 할인율:** 4.0~10.0% (0.5% 단위) 콤보박스, 기본 7% → NPV·할인회수기간 산정. 3/5/7/10% NPV 민감도는 비교용으로 함께 표시.
- **HPS 목표 IRR:** 5~15% (1% 단위) 콤보박스, 기본 10% → 해당 IRR이 되도록 필요 HPS를 이분법으로 역산 (매년 동일 정액 방식 / 원/kWh 방식). 최종 결론에는 기존 매전단가(220원/kWh)에 필요 HPS를 합산한 총 단가도 표시.
- **대수 추천:** 하절기 FC 발생열 ≤ 하절기 총 열부하인 최대 대수 (허용 잉여율 입력 시 완화). NPV·IRR은 비교용이며 선정 기준이 아님. 종합효율 60% 유지 최대 대수는 참고로 병기.
- **현금흐름:** 0~분석기간(기본 20년), 상승률은 2년차부터 적용. 분석기간 내 미회수 시 "미회수"로 표시(연수 임의 산정 금지).

## 핵심 원칙
- 미입력 값을 임의로 생성하지 않음. 빈 칸 = 추가입력 필요, 0 입력 = 0원 확정.
- 미입력 처리 모드: **참고용 제외계산**(제외 항목을 화면에 명시) / **엄격 보류**(미입력이 있으면 경제성 계산 보류).
- 220원/kWh는 "일반 매전단가" / "HPS 포함" 중 선택 → HPS 중복 계상 방지. "HPS 포함" 선택 시 일반 매전단가 입력 필요.
- 사업자 수익과 고객 편익은 합산하지 않음. 누적이익과 NPV는 다른 개념으로 분리 표기.
- 미확정 입력이 남아 있으면 경제성 판정을 "보류"로 두고 조건부 결과로만 표시.
- 기존 검토값(2,704 MWh, 7.92억 등 14개)과 자동 대조: 검증·Excel 탭. (기본 입력에서는 모두 "일치")

## 입력 구분
- **기본값이 채워진 항목:** 세대수·환산면적·실측자료, 냉방부하·COP, 하이브리드 사양, 연료전지 사양·투자비(25억원/대), 가스단가, 동절기 열요금, 고객 전기·수도 요금, 할인율(7%), 목표 IRR(10%).
- **추가입력 필요(기본 빈 칸):** O&M·LTSA, 스택 교체주기·교체비, 보조동력(kW·단가), 보험·제세공과금, 기타 운영비, 가스·전력·열 가격 상승률, 물가상승률, 정부보조금·세액공제, 잔존가치, 철거비, 열배관 손실률, 부분부하 증발수 보정, 보조열원, 축열조 입력 일체.
- 값을 입력하기 전에는 위 비용이 계산에서 빠지므로 IRR·NPV·필요 HPS는 상한(조건부) 값입니다. 확정 판정은 해당 항목을 입력해야 가능합니다.

## Excel 출력
검증·Excel 탭에서 다운로드: 입력조건, 열수요 환산, 냉방 계산, 월별 에너지수지, 종합효율, 월별·연간 사업수지, 매열 내역, 고객 편익, 대수별 비교, 검증, 추가입력 필요, 현금흐름(HPS 전·후), 할인율 민감도, 경제성 요약, 축열조, 최종검토 리포트, 계산식 시트.

## 주의
- 축열조는 일 합계 기준 근사이며 시간 순서별 SOC 시뮬레이션은 포함하지 않습니다.
- 증발수는 냉방열 비례(기본 시나리오)로 계산하며, 부분부하 보정은 값을 입력한 경우에만 별도 시나리오로 표시합니다.
- 검증 탭의 가스비 기준값(7.92억원)은 부가세 처리 전 단가 기준이고, 실제 계산은 부가세 가산 기본값(약 8.71억원/대)을 사용합니다.
